# Bellanopolis · Kollektiv : site web

Site statique publié avec GitHub Pages.

- `index.html` : page d'accueil
- `bellano_studios.html` : location de studio (hub)
- `studio_*.html` : pages studio (photo, vidéo, fond vert, casting, webcast)
- `bellano_casting.html`, `bellano_content_creation.html` : pages services
- `panier.html` : réservation
- `404.html` : page affichée pour les pages pas encore en ligne

Toutes les pages portent `noindex, nofollow` tant que le site n'est pas lancé officiellement.
